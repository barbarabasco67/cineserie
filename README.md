# Cineserie

App móvil de series y películas cozy: videoclub personal, comunidad (Cine, Casa y Cafetería), estrenos y noticias.

- `index.html`: prototipo actual (datos de ejemplo en memoria).
- `schema.sql`: tablas de la base de datos D1.
- `wrangler.toml`: configuración de Cloudflare Pages con la base de datos enlazada.
